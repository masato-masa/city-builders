# 表記の決まり（2026-10-13 調査 → 実装用）

ユーザー指示: ルールが複雑になったので表示・文言を見直す。値が変わる部分（Lv・コスト・効果の数値）はドラクエライバルズ・ポケポケを参考に。
調査の限界: 公式の画面仕様は Web から取れなかった。確かなのは「ライバルズ: 短いキーワードを先頭・数値は符号付き（攻撃力 +3）・条件は文頭」
「ポケポケ: 条件が文頭・主語を省略・固定語（このポケモン）・30+ / 30× の記号」「ハースストーン: 減った体力は赤」。色の最終決定は実機で確かめる。

## 1. 変わった数字の見せ方

| 状況 | 色 | 印 |
|---|---|---|
| 持ち主にとって得（コスト減・収入増・VP 増・相手に払わせる額が増える） | 緑 | ▼（コスト）/ ▲（効果） |
| 持ち主にとって損 | 赤 | ▲（コスト）/ ▼（効果） |
| Lv で上がった値 | 金（★と同色） | なし |
| 変わっていない | 通常 | なし |

- 色は数字の大小でなく「持ち主にとって得か損か」。色だけに頼らず印を付ける。
- バッジは現在値だけ。長押しで「コスト 1（元 3）・城壁で −3」のように**元の値と理由**を出す。
- 条件で決まる数字は、確定値を大きく・式を小さく（例: **7** コイン（5 ＋ 相手の VP 2））。

## 2. 効果文の型

【時点】＋ 対象 ＋ 動作 ＋ 数値。例外・条件は 2 行目以降に 1 行 1 事実。

- 時点の語は「このターン」「次の収入」「次の相手のターン」「次の自分のターン」「ターン開始時」だけ。
- 主語は省く。相手が対象の時だけ「相手の」。
- 数値は「名詞 ±N」（コイン +4、建設費 −2）。「増やす・減らす」と書かない。条件の増え方は「〜につき」。
- コストが変わる条件は「城壁: コスト 0」の形で最後の行。
- 固定語: 次の収入 +N（「コイン」を付けない）／コイン ±N（即時）／建設費／買収費用／物件（「建物」は種類の名前に使う）／地区／〜まで。

## 3. キーワード（文中は下線語、タップで 1 行の定義。あそびかたと共用）

| 語 | 定義 |
|---|---|
| 収入 | 手番の開始時に入るコイン。物件の VP と同じ値 |
| 妨害 | 相手に使う札（徴税官・封鎖者・検査官・顔役・密告者）。守りで防げる |
| 守り | 次の自分のターンまで、妨害と買収を受けない |
| 封鎖 | その地区の空き地に建てられず、地区内の物件の効果が止まる。防げるのは城塞だけ |
| 買収 | 相手の物件を市場価値 × 2 で奪う |
| 市場価値 | 物件の定価（建設＋到達 Lv のアップグレード）。Lv が下がると安くなる |
| 負債 | 次のターン開始時に払うコイン。マイナスになる |

## 4. Lv の見せ方

- ★は Lv1 から 3 枠で常に出す（★☆☆ / ★★☆ / ★★★）。
- 次の Lv の説明は全文の再表示をやめ、変わる数字だけ「収入 +4 → **+5**」を 1 行。
- 次の Lv までの回数は点（●○）で出し、使うたびに塗る。Lv が上がった瞬間は新しい値を金で光らせる。
- 物件の詳細も同じ形。VP（＝収入）の行を 1 行目に固定。

## 6. 実装の指示

1. `cardTextFor` / `buildingTextFor` を「行の配列（主文＋補足行）」に。数字は `{value, kind: 'lv' | 'good' | 'bad', base?, reason?}` を付けて返し、描画側で色と印。
2. キーワードの定義表を 1 か所に（`help-content.ts` と共用）。文中は下線語、タップで定義。
3. ★の 3 枠、次の Lv の差分 1 行、使用回数の点。
4. あそびかたに「色と印の意味」を 1 画面で。

記事の要点（自分の言葉）
- ポケポケ: UI の文字は最小限。ラベルが無くても触れば覚えるので、丁寧にしすぎて煩雑にするより削ぐ。
- ポケポケ: 数字（Lv など）は本文と別系統の字体で目立たせる。基準 1080×2340 で本文 32〜34px、最小 22px。
- シャドバ: 本文 32〜34px、最小（ルビ）16〜18px。ヘッダー数値は本文より大きい 36〜38px。画面の役割ごとに UI の表現を切り替え、無理に統一しない。
- カオゼロ: 本文 32〜34pt、最小 16〜18pt。細い字で装飾を抑える。

画像で確かめた事実
- ポケポケのカード拡大: 1 つの技が 1 行（左にエネルギー記号、中央に技名、右端にダメージ数字を大きく）。効果文はその下に小さい 1〜2 行で、記号は文中に埋め込む。HP は右上、弱点「+20」は下段に分けて固定位置。段階（★）は左下。
- ポケポケの対戦: 与えたダメージは受けた側のカード上に数字バッジで重ねる。ポイントは ①②③ の丸と「+1 ポイント！」の帯。結果画面は項目と数値の 2 列表。
- シャドバのカード: 左上にコスト（緑丸）、下の左右に攻撃と体力（青・赤）。数字は絵の隅に置き、効果文は拡大時に出す（一覧では出さない）。
- 変化時の色・印、Lv 段階の見せ方、長押しの出し分け: 見えず。

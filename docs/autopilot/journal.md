## 2026-10-10 回転が強い原因と、投資の利回りの調整（ブランチ balance-round、未公開）

- 原因の特定（性格別の内訳を取る使い捨てツール、200 試合/組）: 回転（＝ゲーム内 CPU と同じ重み）は採掘師 32.7%・銀行家 23.6% のターンで投資し、投資収入が 1 試合 67 コイン（他は 28〜46）。
  回転だけカードを禁止すると 63.7% → 採掘師 44.0% / 銀行家 36.8%（他のカードは −0〜8 点）。**回転を支えていたのは採掘師・銀行家の利回り**（銀行家 5 コストで次の収入 6+2/件）。物件は城塞の建設が多い（0.86 件/試合、他 0.26〜0.52）が、城塞の VP・通行料を下げても回転は動かなかった。
- もう 1 つの原因は CPU の盲点: `incomePerTurnOf` が祝祭を「毎ターンの収入が倍」と数えていた。均衡（序盤の incomePerTurn 24）が祝祭・伝令を 25% のターンで撃ち、均衡だけ祝祭を禁止すると 37.1% → 47.0%。
  祝祭の上乗せを 1 度きり（`festivalExtraOf`、投資カードと同じ pendingIncome の物差し）にした。
- 数値: 採掘師 次の収入 +4 → +3、銀行家（6 + 2/件）→（5 + 1/件）、封鎖者 4 → 5（3/5/6/8 で禁止 25.9/44.1/47.1/48.5%）。
  銀行家の基本を下げる・コスト 6・採掘師コスト 3 などは回転が 58〜71% に残った。祝祭の上乗せ +3 は回転が 60.7% に戻るので不採用。
- 最終の既定値（phase5-balance を取り込んだ後）:

| 指標 | 前 | 後 |
|---|---|---|
| lab 150（回転 / 妨害 / 大器晩成 / 均衡） | 64.4 / 55.6 / 41.4 / 38.6% | 55.8 / 45.9 / 50.7 / 47.7% |
| 先手 | 49.8% | 46.9% |
| card-value 採掘師 | 36.3 / 51.0 | 36.1 / 50.6 |
| 銀行家 | 39.4 / 61.6 | 42.5 / 42.6 |
| 封鎖者 | 32.6 / 36.4（祝祭の修正後） | 44.1 / 44.0 |
| ladder つよい対ふつう | 85.5% | 92.0% |

- 回帰テストの最終コイン残高は凍結した FROZEN_BALANCE で回す（数値の調整では動かない）。
- 残り: 採掘師の禁止 36%（安い投資はまだ必須級）、祝祭の優先 38.5%、先手 46.9%（下限ぎりぎり）、つよい対ふつう 92%（上に外れた。CPU の評価が強くなった分）。

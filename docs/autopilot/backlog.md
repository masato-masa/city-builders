## UX の指摘（実画面評価より、2 と一緒に）

- 用語: 「次のターン」→「次の収入」に統一。灰色の行に理由の一文。
- 伝令モードの案内バナーが右上のタイマーと重なる。シートの高さが毎回違い、ボタンの位置が動く。
- 手札のコスト不足に「あと何コイン」を出す。
- 「のこり N ターン」の時計の意味が初見で分からない。
- CPU が使ったカードが盤面中央に出て建物を隠す。

## 計測の道具

- `npm run card-value -- 400 [カード…]`（禁止/優先の勝率、`BALANCE='{...}'` で上書き）約 3 分。
- `npm run lab -- 100`（性格の総当たり、約 5 分、誤差 ±5%）。
- `npm run search`（重みの探索、約 64 分）。

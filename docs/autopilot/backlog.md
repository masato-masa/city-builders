## 調査で出た課題（優先は上の後）

- 衛兵は使うほうが損（禁止すると 60%）、買収者は無価値（優先すると 29%）。1 の追加で価値が変わるので、その後に測り直す。
- 普通 CPU が弱い（パスだけでも勝てた）。高利貸の評価を見直す。
- 用語: 「次のターン」→「次の収入」に統一。灰色の行に理由の一文。
- 伝令モードの案内バナーが右上のタイマーと重なる。シートの高さが毎回違い、ボタンの位置が動く。
- 手札のコスト不足の表示に「あと何コイン」を出す。
- 画面揺れ・ヒットストップが無い（standards.md の演出）。
- 演出の参考にドラクエライバルズ（ユーザー提案）。調査担当が事実を集める → standards.md に取り込み、カード使用・買収・勝利の演出へ。

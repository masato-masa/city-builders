# 独占・連携・新カードの調査（2026-10-10、opus の調査担当）

出典の多くは検索の要約。数値と効果は**案**であり、実装時に `card-value` / `lab` で測って直す。

## 独占ボーナスの案

市場 10 区画を 3 エリア（0-2 / 3-5 / 6-9）に分ける。
- **B 多数派の称号（推奨）**: エリアの過半数（2 件以上）を持つ側に +2VP。同数なら今の持ち主が保持。
  買収 1 回で称号ごと動くので、買収・衛兵・封鎖者の価値が上がる。
- A 色セット: 全部持つと +3VP と買収価格 +3（序盤に取った側が雪だるま式に有利）。
- C 毎試合のエリアルール抽選（手間が大きい。後回し）。

## 物件×人物カードの連携（案 8 組）

報酬はコインでなく、コスト 0・VP・買収価格・期間で出す（お金系に連携を足さない）。

| 組 | 効果 | 狙い |
|---|---|---|
| 城壁×衛兵 | 衛兵のコスト 0、効果が 2 ターン続く | 衛兵を「使うと損」でなくする |
| 城塞×封鎖者 | 止めた相手物件の VP も 0 | 封鎖者を VP 争いに効かせる |
| 工場×買収者 | 買収者を使ったターン、物件の買収価格 −3 | 買収者に役目 |
| 取引所×徴税官 | 取引所を「徴税で引いた額の半分を自分の次の収入に」へ置き換え | 取引所がお金系一強を強めているのを外す |
| 街道×伝令 | 伝令のコスト 0、2 枚まで送れる | 伝令を手札回しデッキの核に |
| 大聖堂×祝祭 | 祝祭のターンのアップグレード費 −50% | 祝祭を「発展」の出口に |
| 商館×高利貸 | 商館 1 件につき借り −1 | 安い物件に役目 |
| 石切場×封鎖者 | 封鎖した空き地に次のターン自分だけ −3 で建てられる | 封鎖者に攻めの使い道 |

## 新しい建物・カードの案

建物: 見張り塔（9/2VP、自分の物件の買収価格 +3）、関所（12/2VP、相手の採掘師・銀行家の収入のうち 2 を自分がもらう）、
密偵の宿（11/2VP、妨害カードのコスト −2）、市庁舎（15/3VP、同エリアの自分の他の物件 1 件につき +1VP）。
カード: 地上げ屋（2、このターン買収価格 −4）、検査官（3、相手の Lv2 物件を Lv1 に戻す。払われた合計は残る）、
密告者（1、相手が次に引くカードを見て底へ送らせる）、職人（2、このターンのアップグレード費 −4）。

## ドラフト（推奨）

固定コア 4 枚（採掘師・建築家・衛兵・伝令）+ 3 択 × 6 回 = 10 枚。3 択は両者に同じ 3 枚を公開で見せる。
銀行家はコアに入れない。軽い代替: ドミニオン式に 14 種から 10 種をシードで抽選し両者で共有（時間 0、決定的）。
**注意**: 買収は空き地を埋めないので、試合の終わりが「20 手番の上限」頼みになりうる。終了条件は実測で決める。

## 推奨順位（効果 / 実装 / 崩壊の危険）

1. 取引所の作り替え + 妨害系の連携 4 組（城壁×衛兵・城塞×封鎖者・工場×買収者・取引所×徴税官）: 大 / 小 / 中
2. 多数派の称号 +2VP: 大 / 中 / 低〜中
3. 地上げ屋・検査官: 中〜大 / 中 / 中
4. 関所・見張り塔: 中 / 小 / 中（関所は強すぎる恐れ）
5. 連携の残り 4 組: 中 / 小 / 低
6. ドラフト: 大 / 大 / 低
7. 独占案 C・密告者・市庁舎: 中 / 大 / 中〜高

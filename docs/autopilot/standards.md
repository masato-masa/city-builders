# 基準（standards）

他のゲーム・制作者の知見から決めた合格ライン。**非公式の出どころが多いので「出発点」**であり、
実測や実プレイで直してよい。直したら journal に書く。調査日: 2026-10-10。

信頼度: ◎ 開発元の公式記事 / ○ 制作者の実測や複数の一致 / △ ブログ・チュートリアル 1 本

## 1. 演出（手触り）

| 項目 | 基準 | 信頼度 |
|---|---|---|
| ヒットストップ | 軽い打撃 50ms / 重い打撃 80〜100ms。30ms は気づかれず、150ms は重く見える | ○ |
| 画面揺れの振幅 | 軽 2〜3px / 重 8〜10px。長さは 50〜100ms | △ |
| 画面揺れの使いどころ | 衝撃のみ。通常の操作には付けない。大きな揺れは酔う | ○ |
| ボタンを押した時の縮み | 80〜120ms、倍率 0.9 前後（0.92 で心地よい例） | △ |
| パーティクル | 初速 200〜400px/s、0.5〜1 秒で消える、1 回 20〜30 個まで（多いと散らかる） | △ |
| UI の深さ | 画面の階層は 1 段まで。ポップアップは全画面にしない（クラロワの分析） | ○ |
| カードの状態表示 | 名前・コスト・使えるかが常に一目で分かる | ○ |

出典:
- [Game Feel & Juice](https://www.wayline.io/learn/game-feel/1)
- [Where Does Game Feel Come From](https://eastondev.com/blog/en/posts/dev/20260521-game-feedback-feel/)
- [Clash Royale UX の分析](https://discover.therookies.co/2020/02/24/game-design-ux-best-practices-detailed-breakdown-of-clash-royale/)

**未入手**: クラロワの具体的な秒数・イージング（検索では出なかった）。
動画をコマ送りした実測が必要。→ backlog。

## 2. 音

| 項目 | 基準 | 信頼度 |
|---|---|---|
| 1 動作の構成 | 高い「カチ」（輪郭）+ 中域の「本体」（性格）+ 低い「ドン」（重さ）の 3 層 | △ |
| 立ち上がりと余韻 | 速い立ち上がり、短い余韻。長い余韻は速い連続動作を濁らせる | ○ |
| 同じ音の変化 | 繰り返される音は 3〜5 種類の候補 + 小さな音程・音量のゆらぎ | ○ |
| 全体の音量 | 目安 -14〜-16 LUFS、ピークは 0dBFS 未満 | △（モバイル固有の規格は未確認） |
| BGM の音量 | 効果音より -6〜-12dB | △ |
| 容量 | 全音源で 10〜50MB の範囲に収める | △ |

出典:
- [Game Audio & Sound Design](https://www.wayline.io/learn/game-audio/1)
- [音の重ね方（フォーラム）](https://itch.io/t/30552/dynamic-sound-effects)

現状: 16 種・各 1 本・1.2MB。層は 1 枚で、変化は音程・音量のゆらぎのみ。

## 3. ゲーム性（カードゲーム）

| 項目 | 基準 | 信頼度 |
|---|---|---|
| カードの勝率 | 全体で 50% に近づける。ハースストーンのアリーナは調整幅を ±30% 以内、全体の増減が相殺するよう調整 | ◎ |
| 勝率の許容幅 | 全体 48〜52%、上位者で 45〜55%（Gods Unchained の目標） | ○ |
| 先手の勝率 | 公開例は 45〜49%（Shadowverse）。**先手 ±3% 以内を目標** | ○ |
| 標本数 | 100 試合では 50% と 55% を区別できない。1 組あたり 1000 試合以上で判断する | ○ |
| コスト曲線 | 安いカードが一番多く、高いほど少ない（例: 1 コスト 8〜12、2 コスト 8〜10、3 コスト 6〜8、4 コスト 2〜4、5 以上 0〜2） | △ |
| カードの強さ | 同じコストなら同じ強さ。逸脱は代償（弱点）で払う | ○ |
| 勝率だけで見ない | 技量差・組み合わせ・環境で 50% にはならない。採用率と、使った時の勝率の両方を見る | ○ |

出典:
- [Hearthstone: Arena Balance Through Science](https://playhearthstone.com/en-us/blog/22788308)
- [The Balance Charter（Gods Unchained）](https://portal.godsunchained.com/blog/the-balance-charter)
- [Shadowverse の勝率分析](https://shadowverse.com/news/important/news-0051)
- [カードを全体勝率で分析する誤り](https://outof.cards/comments/172673)

**未入手**: 逆転率・ゲーム長の目安（信頼できる出典が見つからなかった）。

## 4. このゲーム固有の合格ライン（上を踏まえて決めた）

| 指標 | 合格 |
|---|---|
| 1 枚のカードの採用率 | 全カードが、使える場面で 5% 以上は選ばれる（死にカード無し） |
| 1 枚のカードの勝率差 | 使った時の勝率が 50±5%（1000 試合以上で測る） |
| 戦略の勝ち越し | 4 つの性格（均衡・妨害・回転・大器晩成）の総当たりで、誰も 55% を超えない |
| 先手の勝率 | 47〜53% |
| ゲーム長 | 要測定（現状値を取ってから決める） |
| 逆転率 | 要測定 |
